# Naash Coffee 3D pack viewer

A single-file, real-time 3D viewer for Naash Coffee stand-up pouches, built with [three.js](https://threejs.org/).

- Six label designs (Aroma Wheel, Contour, Bold Cream, Steam, Kraft Classic, Highland Pattern)
- 250 G and 1 KG sizes, front / back / side views, auto-rotate
- "All six designs" lineup
- Click the valve (or press "Squeeze & smell") to squeeze the bag and release aroma puffs

## Run

Open `index.html` in a browser. It loads three.js (r128) and fonts from CDNs, so it needs an internet connection.
To host it, enable GitHub Pages for this repository and open `/naash-3d-viewer/`.

Origins, grades, tasting notes, address and dates on the labels are sample copy.
